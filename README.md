5. Description of the Program: 
This project is a Java Swing application that demonstrates how a stack works using the Last In, First Out (LIFO) principle. It allows users to perform stack operations and view the current stack contents through a coffee-themed graphical user interface.

6. Features:
Push a value into the stack.
Pop the top element from the stack.
Peek at the top element without removing it.
Clear all elements from the stack.
Check whether the stack is empty.
Generate a random stack.
Display the current stack size and top element.
Show status messages for successful operations, overflow, and underflow.
Display stack elements vertically, with the newest element at the top.
Use an array-based stack with a maximum capacity of 10 elements.

7. Requirements:
Java Development Kit (JDK)
NetBeans IDE or another Java IDE
Java Swing library
A computer capable of running Java applications

8. How to Run the Program: Open NetBeans IDE. Open the project. Make sure the source files are in the correct package. Set StackGUI.java as the main class if needed. Build the project. Run the program.
Enter a value and click the desired stack operation button.

9. Project Structure: The project contains separate classes for stack operations and the graphical user interface.
StackModel.java – manages the stack data and its operations.
StackGUI.java – handles the graphical interface, user input, buttons, and stack visualization.

10. Stack Implementation: The program uses an array-based stack with a maximum capacity of 10 elements. It follows the LIFO principle, meaning the last element added is the first element removed.
The stack class provides methods such as push(), pop(), peek(), isEmpty(), isFull(), size(), and clear(). The GUI accesses the stack through these methods instead of directly modifying its internal data.
